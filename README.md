# Database exercises

School exercises and practice material for learning MySQL and relational databases.

## Repository structure

- `exercises/` — SQL query exercises covering filtering, joins, grouping, functions, constraints, inserts, and subqueries.
- `sample-databases/` — database creation scripts used to run the exercises locally.

## Topics

- `SELECT`, `WHERE`, and `ORDER BY`
- Aggregate functions
- `GROUP BY` and `HAVING`
- Joins
- Subqueries
- Constraints
- Inserting data

## Running the exercises

1. Install MySQL locally.
2. Import the required script from `sample-databases/`.
3. Open one of the files in `exercises/` and run its statements in MySQL Workbench.

Some exercise files intentionally show intermediate attempts made while learning SQL.
